# 01 · 版式库（只写内容，不写坐标）

> 官方希沃技能（`seewo-easinote-assistant-skill`）的 `page_structure_guide.md` 明说：
> 它只给**页面结构的语汇与组织逻辑**，**不提供任何像素坐标**，也"不是可机械轮换的版式模板"。
> 每页坐标、字号、行高全靠 AI 当场现编 ⇒ 同课两次可能长得不一样、易排歪压叠。
>
> **版式库补的就是这块**：把已验证的构图固化成**参数化模板**，下次只写内容不写坐标。

```
一句话（简报 JSON） → make_deck.py → pages.json → 官方技能落稿 → 插视频/分组/动效 → 上云
```

---

## 一条命令

```bash
cd <skill>/scripts/版式库
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy

PY="python"    # 换成你本机备齐依赖（pymupdf / Pillow / opencv / python-docx）的 Python 3
"$PY" make_deck.py --brief "briefs/第6课-植物的繁殖.json" --out "../第6课-植物的繁殖/pages.json"
"$PY" check_geometry.py --spec "../第6课-植物的繁殖/pages.json"     # 几何体检（推荐）
```

生成器**写文件前会内联调用技能自己的校验器**（`validate_deck`）⇒ "生成了但过不了校验"不会流到落稿阶段。

## 模板清单（12 套）

| 版式名 | 名称 | 适用场景 | 页型 | 密度门槛 | 可填内容 |
|---|---|---|---|---|---|
| `cover` | 封面 | 课题首屏 | 内容页 | 不计入 | title / lead（学段）/ body（副题） |
| `bullets` | 竖条要点列 | 导入、单栏要点讲解 | 内容页 | moment 80 | title / lead / body / items |
| `evidence` | 证据 + 追问 | 探究页（证据 → 收束追问） | 内容页 | evidence 100 | title / lead / body / items / question |
| `record_table` | 记录表 | 观察记录（希沃表格组件） | 工具页 | 不校验字数 | title / lead + `table`(markdown) |
| `mindmap` | 思维导图 | 分类归纳（希沃脑图组件） | 工具页 | 说明文字 ≥60 | title / lead / items + `markdown` |
| `cards3` | 三卡片 + 结论条 | 实践方案、三种做法并列 | 内容页 | sequence 120 | title / lead / body / items(3) / summary |
| `two_col` | 双栏并列 | 对比、辨析 | 内容页 | compare 120 | title / lead / items(2) / summary |
| `steps` | 步骤流程 | 实验步骤、生长变化 | 内容页 | sequence 120 | title / lead / body / items(2–6) |
| `conclusion` | 结论条 | 课堂总结 | 内容页 | summary 80 | title / lead / summary / body / items |
| `match` | 配对活动 | 希沃配对组件 | 活动页 | 不校验字数 | `pairs`(≥3 组) |
| `photo_pair` | 双图对照 | 两种事物并置（图文混排） | 内容页 | sequence 120 | title / lead / items + `images` |
| `photo_trio` | 三图并列 | 三张图并排 | 内容页 | sequence 120 | title / lead + `images` |

**选版式的一条硬规则**：**相邻两页不要用同一个版式**。校验器会算"版面轮廓相似度"，
相邻教学页 **≥82% 直接报错**；整册 ≥6 页时还需 **≥4 种不同轮廓**。
`make_deck.py` 会打印实际轮廓种类，够不够一眼可见。

> ⚠️ `variant` 只改内容不改轮廓 —— 想换轮廓必须换**真版式**。

## 内容密度门槛（技能会拦，务必先看）

技能规定"内容页不能只有一句结论"，按 `teachingIntent` 卡字数：

| intent | 硬下限（低于**报错**） | 建议值（低于只告警） |
|---|---|---|
| `moment` | 80 字 | 120 字 |
| `evidence` | 100 字 | 150 字 |
| `summary` | 80 字 | 120 字 |
| `sequence` / `compare` | **120 字** | 180 字 |
| `practice` | 100 字 | 150 字 |

（字数 = `title + lead + body + question + summary + 各条 items` 合计；封面不计、工具页与活动页不校验。`items` 写对象形式时 `text` 需 ≥24 字。）

想放宽某页门槛 → 在简报里改它的 `intent`（如 `{"layout":"steps","intent":"evidence"}`：120→100）。
`pagePlan.range`（如 `[5,10]`）是**有效内容页数**区间，封面/目录/章节页不计入，超出也报错。

### 另两条内容规则（会告警）

- **每页至少 3 层信息**：`lead/body/items/question/answer/summary` 里用到**≥3 种**。
- **`anti_pattern` 不能空**：每页写**本页具体禁止项**（写空或泛泛之词会告警）。

## 简报怎么写

只写内容和版式，**一个坐标都不写**：

```json
{
  "spec": {
    "title": "第6课 植物的繁殖",
    "subject": "科学", "grade": "四年级", "topic": "植物的繁殖",
    "pagePlan": { "range": [5, 10] },
    "teachingObjectives": ["…", "…"],
    "creativeDirection": { "concept": "…", "visualMetaphor": "…", "backgroundStrategy": "…" }
  },
  "theme": "teal",
  "pages": [
    { "layout": "cover",   "title": "…", "lead": "…", "body": "…" },
    { "layout": "bullets", "title": "…", "lead": "…", "body": "…",
      "items": ["…", "…", "…"], "anti_pattern": "本页不要做什么" }
  ]
}
```

- **不必填满所有字段**；多写的会被忽略并**明确告警**（不静默丢内容）。
- `items` 可为字符串数组，或 `{"title":"…","text":"…"}` 对象数组。
- `anti_pattern` / `rationale` 可选；`rationale` 写进 `visualPlan.designRationale`（技能要求非空，不写则用模板说明）。

### 配图契约

- 图源写 `[src,x,y,w,h,caption?]` 或 `{"src","role","box","caption"}`；`role ∈ (illustration,photo,diagram,data)`。
- 图注 10–80 字、**上限 2 行**（22px）；**带图注时图宽 ≥200px、高 ≥60px**（178px 会被拒）。
- 图面积 ≤0.8·W·H；`fit` 只 `"cover"` 合法。
- ⚠️ 模板自己消费 `images` 的（cover/photo_pair/photo_trio/two_col/steps/evidence/bullets），**不要**再追加一次，否则同图渲染两遍。
- ⚠️ `cards3` **禁止配图**（卡片仅 164px 矮）—— 要配图改 `photo_trio`。

## 换配色：改一个地方

`theme.py` 是整套色板，**没有任何模板写死色值**：

```jsonc
"theme": "teal"                                     // 用预设（内置 teal / ochre）
"theme": { "preset": "teal", "gold": "#D9A441" }    // 预设 + 个别覆盖
"theme": { "deep": "#0F4C5C", "paper": "#F6F3EC" }  // 只改要改的几个
```

可改色名：`deep/mid/accent/light/paper/ink/gold/white/meta/sub/cardInk`。色名写错**直接报错**。
⚠️ 换色后必跑 `make_deck.py`：校验器按 WCAG 算对比度（错误线 3:1、建议线 4.5:1），不过线在生成阶段就拦下。

## 库内保证的三件事

1. **文本框不会被渲染端偷偷撑高**。渲染器行为是"不缩字号、框偏矮就往下撑"（`fit=False`）。
   内容页框高按客户端真实行高（**1.42** 系数）反算，声明即所需。`check_geometry.py` 应报内容页 **0 个**被撑高。
2. **装不下就报错，不静默缩字**。`flow()` 逐级降字号（下限：标题 42px / 正文 22px），仍排不下就抛错并**指出哪几句话超了**。
3. **不压希沃原生组件安全区**。表格/脑图用通用安全槽（`y≥234`），元素框与它重叠 >2% 直接报错。

### 一处已知取舍：工具页允许被撑高

表格页/脑图页是唯一例外 —— **刻意按校验口径（1.0 系数）声明框高**，把头部整条收在 `y=234` 之上；
撑高的那点落进组件自带的空白内边距（实测脑图可视节点从 `y≈360` 起、表格从 `y≈237` 起），视觉看不见。
`check_geometry.py` 会单列它们并标"允许的撑高"。

## 文件清单（`scripts/版式库/`）

| 文件 | 作用 |
|---|---|
| `theme.py` | 色板与预设（换配色只改这里 / 或在简报里覆盖） |
| `layouts.py` | 12 套参数化模板 + 度量/流式排版/自动算框高 |
| `make_deck.py` | 简报 → `pages.json`，并内联跑技能校验 |
| `check_geometry.py` | 几何体检（越界 / 压安全槽 / 文本压叠 / 渲染零增长） |
| `typography.py` | 字体方案 + scale（见 `06-字体.md`） |
| `anim_presets.py` | 教学意图 → 动效方案（见 `02-动效能力边界.md`） |
| `briefs/*.json` | 样例简报 |

依赖：`layouts.py` 会读本机希沃技能的 `components.py` / `rich_text.py`（**只读**）。技能装在别处时：
```bash
export SEEWO_SKILL_DIR=".../seewo-easinote-assistant-skill__skillhub"
```

> 动效（`anim_presets.py` / `group.json` / `anim.json`）见 **`02-动效能力边界.md`**。
