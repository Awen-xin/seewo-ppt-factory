# 06 · 字体（渲染链 · 墨迹实测 · 方案）

> 目的：把课件字体换成"后排看得清"的，或整套单元统一风格。

---

## 一、字体渲染链（换字体全靠这个）

```
layouts.py:_t()  →  style 字典  →  page_renderer.py:115  style.get("font","Microsoft YaHei")
    →  C.add_rich_text(font=…)  →  enbx_backend._run_xml(font=…)
    →  XML <FontFamily><Source>字体名</Source></FontFamily>
```

🔑 **键名是 `"font"`，不是 `fontFamily`。**
🔴 **图注字体在 `page_renderer.py:89` 是硬编码雅黑**，不受 style 影响（所以字体版里总会残留若干处雅黑=图注）。

---

## 二、墨迹实测：这些字到底"实不实"

同一句课文、同一字号渲染，统计"墨迹像素占比"——占比越高笔画越粗、后排越看得清：

| 字体 | 墨迹占比（相对雅黑） | ≈等效放大 | 说明 |
|---|---|---|---|
| 微软雅黑（基准） | 1.00 | — | 现状 |
| **微软雅黑 加粗** | **1.60×（+26.6%）** | +26.6% | 最粗，**零成本**（系统自带） |
| **汉仪旗黑 80S** | **1.38×（+17.3%）** | +17.3% | 汉仪里最粗，方头方尾 |
| 汉仪润圆-75W | 1.13×（+6.3%） | +6.3% | 圆头圆尾，有温度但偏细 |
| 汉仪旗黑 60S | 1.03×（+1.3%） | +1.3% | 与雅黑几乎一样重 |

（原始量值：雅黑 33.1% / 雅黑Bold 51.4% / 旗黑80S 42.1% / 润圆75W 35.1% / 旗黑60S 31.8%。）
实测工具：`scripts/measure_font_gain.py`。

⇒ **汉仪这批只有旗黑 80S 明显粗过雅黑；润圆整族都更细**（45W 细 16%）。
⇒ "后排看不清"要么用**旗黑 80S**，要么直接**雅黑加粗**（零成本、比 80S 还粗）。

## 三、🔴 `_t()` 的 bold 分支会静默吃掉圆体

`question` / `summary` 在模板里**恒定 `bold=True`**（深底白字强调条），`title` 在 conclusion/_tool_header 里也是。
⇒ 这些角色实际永远走 **`fonts_bold`** 路径，**圆体必须写在 `fonts_bold` 里**，写 `fonts` 会被跳过（实测润圆一个没落上）。
`fonts_bold` 命中后会吃掉 bold 标记（避免客户端伪粗糊笔画）。

---

## 四、🔴 字号放大的硬上限 = 1.02（内容不变时）

内容不变时全局 scale 只能到 **1.02**，1.03 就报错。瓶颈页：
- **`evidence` 页**：lead 43 字 + body 89 字 + 3 items
- **`bullets` 页**：3 items（各 26–30 字，2 行）+ 2 图，`y=490` 起

⇒ 想要更大字号**必须先精简这两页文案**。
⚠️ `flow()` 装不下会**自动降到 min** ⇒ **只改 `size` 不改 `min` 等于白改**；`flow()`/`autosize()` 里 `size` 与 `min` 必须**同乘 scale**。

## 五、方案（预设）

`typography.py` 提供预设（`PRESETS`）：

| 预设 | 内容 |
|---|---|
| `hanyi-science` | 标题 旗黑80S / 正文 旗黑60S / 结论+提问 润圆75W（**与第7课统一**） |
| `hanyi-max-size` | 同上 + scale 1.02 |
| `larger-only` | 只放大不改字体 |
| `hanyi-keep-size` | 只换字体不放大 |

用法：简报里加 `"typography": "hanyi-science"`。

**推荐**（给纠结的场合）：
- 想**整套单元统一 + 好看** → `hanyi-science`（C 方案）
- 想要**最清晰** → 正文用雅黑加粗（E 混搭 / B 全加粗），零成本、无授权风险
- 想看样张再定 → `scripts/render_samples.py` 出 A–E 样张 + `字体选择.html`

## 六、装字体

`install_fonts.py`：复制 ttf 到 `C:\Windows\Fonts` + 写 HKLM 注册表（**用 Python 做，绕开 PS5.1 的 GBK 坑**）。
字体源在 `hanyi-font-library` 技能的 `pairing-presets.json`（`oss_url`）；字体名取 fontTools 的 **nameID=4 中文全名**。
**装完希沃客户端需重启才认**（实测：客户端已启动时注入的名字也能正常渲染，通常无需重启）。
