# 00 · 上游：教材准备（先提教材，再做课件）

> 本技能（`seewo-courseware-pipeline` / 希沃课件工厂）的输入是一份**简报 JSON**。
> 简报之前，素材（教材正文 + 插图）要先备好。本文件说明**上游链路与衔接点**。

---

## 正确顺序（用户明确的流程）

```
① 提教材进本地库            ② 抽教材插图            ③ 写简报            ④ 做希沃课件
国家智慧中小学教材提取技能  →  scripts/教材取图.py  →  brief.json  →  本技能全流程
(smartedu-textbook-organize)                          （只写内容）
```

**一句话**：先用「教材提取」把教材落到本地知识库，再用本技能做希沃课件。**不要跳过第①步去凭空编内容。**

---

## ① 提教材 → 交给 `smartedu-textbook-organize`

**不要在本技能里重复实现下载**。直接复用已有技能：

| 技能 | 作用 |
|---|---|
| `smartedu-textbook-organize` | 「国家智慧中小学教材提取」（别名「教材管家」）**总控**：一句话跑完检索→取凭证→下载→版次核对→切分单元 MD→归档 |
| `smartedu-textbook-download` | 底层下载（被上面调用） |
| `ima-kb-upload` | 可选：把教材入库到 IMA 知识库 |

**产出落位**（记忆中的项目约定）：

```
知识库/{学科}/01-教材/{版本}{年级}{册}/
    ├─ 教材 PDF
    └─ 单元级 Markdown（正文/课时表）
```

- **一学科一库**，库 ID 登记在 `知识库/_IMA库登记.md`。
- 版次用 `check_edition.py` 核对（平台会换版；粤教版四上/五上/六上已换 2026年7月第1版）。
- ⚠️ 该技能**只提教材 PDF**，不提教案/课件/视频（那些在平台另一板块，公开 CDN 返 403）。

**触发词**："帮我整理XX学科X年级教材""下载XX教材存到知识库""教材入库"。

---

## ② 抽教材插图 → `scripts/教材取图.py`

从教材 PDF 里抽出本课要用的插图（CMYK→RGB 存 JPG），并整页渲染 PNG 供人工核对。

> ⚠️ 本脚本从原 `_extract_pdf_imgs.py`（第6课版）/`_extract_l7.py`（第7课版）**提升为通用工具**：
> 内置「PDF 页序 = 印刷页码 + 偏移」的映射核对，**新册次务必先 `get_text()` 逐页打印前 90 字核对**，别直接套用偏移。

输出：`{课}/配图/*.jpg`（命名建议 `P{印刷页码}_img{n}.jpg`）。

---

## ③ 写简报 → `references/01-版式库.md`

只写**内容 + 想用的版式**，**一个坐标都不要写**。字段与门槛见 `01-版式库.md`。
样例：`assets/briefs/第6课-植物的繁殖.json`（最简）、`第8课-蚕的一生.json`（最新）。

---

## ④ 交付给本技能

简报写好 → 进 `SKILL.md` 的「一条流水线」。整条顺序不可换，尤其：
**视频注入必须在内容定稿之后**（`enbx_video` 会整页重写）。

---

## 边界（本技能不做什么）

- ❌ 不下载教材、不解析平台（交 `smartedu-textbook-organize`）
- ❌ 不生成"单文件 HTML 互动课件"（那是 `textbook-unit-courseware` / `teachany`，另一种产物）
- ✅ 只做：简报 → 希沃原生 `enbx`（含视频、分组、动效）→ 上云 → 验收
