# 02 · 动效能力边界（实测结论）

> 适用：希沃白板 5 客户端（EN-PC-5.2.4.11451），Windows，通过 enbx XML 后处理注入动画。
> 所有结论均为**实测**（造探针课件 → 客户端打开 → 上云 → 回读客户端自己序列化的 XML → 三态判定：存活 / 被改写 / 被丢弃）。

---

## 一、五类"够用型"能力的结论

| 想要的效果 | 结论 | 写法 |
|---|---|---|
| 自动播放 | ❌ **不可用** | `Trigger=AutoPlay` / `AfterPrevious` 一律被改写成 `Click` |
| 点击消失 | ✅ 可用 | `Category=Disappearance` + `FadeOut` / `RippleOutEffect`，`Trigger=Click` |
| 强调闪烁 | ✅ 可用 | `Category=Emphasis` + `Flicker` / `Shake` / `Heartbeat` / `Bounce` |
| 沿路径移动 | ❌ **不可用** | `Category=Path` 被改写回 `Appearance` |
| 配音效 | ❌ **不可用** | `<Audio>` / `<Sound>` / `<SoundEffect>` / `<AudioId>` 被**静默丢弃** |

**一句话**：进入 / 退出 / 强调 三类 + 点击触发 = 全部能力；路径、音效、自动播放都做不到。

---

## 二、⚠️ 两个"炸整份课件"的雷（务必避开）

这两个字段**不会**只让一个动画失效，而是让**整份课件加载失败**（打开后只有 1 页 / 页面全丢），
且 XML 语法完全合法 —— 解析器查不出，只有真机打开才暴露。

| 雷 | 现象 | 正确写法 |
|---|---|---|
| `Trigger=WithPrevious` | 打开后 `slideCount=1`，所有页丢失 | 要"同时动"→ 用 `<Group>`（见第五节） |
| `<Magnitude>Large</Magnitude>`（强调类） | 同上，整份加载失败 | 只写 `Medium` 或**省略**（客户端自动补 `Medium`）。`<Frequency>` 改大安全 |

排障：怀疑课件坏了时先跑 `_open_check.py`（**只打开、不同步** ⇒ 不产生云端副本），报 `slideCount`。
原版正常、探针只有 1 页 ⇒ 是探针内容问题，不是 XML 语法问题。

## 三、类别 / 触发 / 字段 边界

### 3.1 类别（Category）

| 类别 | 状态 | 说明 |
|---|---|---|
| `Appearance` | ✅ | 进入 |
| `Disappearance` | ✅ | 退出 |
| `Emphasis` | ✅ | 强调 |
| `Path` | ❌ | 被改写回 `Appearance` |

### 3.2 触发（Trigger）

| 触发 | 状态 | 说明 |
|---|---|---|
| `Click` | ✅ | **唯一稳定可用** |
| `WithPrevious` | ❗ | 会让整份课件加载失败 |
| `AutoPlay` / `AfterPrevious` | ❌ | 被改写为 `Click` |

### 3.3 客户端回写后的动画 schema（照抄，勿改字段集）

```xml
<Animations>
  <Animation>
    <Type>RippleInEffect</Type>        <!-- 见第四节 -->
    <Id>32位hex</Id>
    <Number>1</Number>                 <!-- 本页第几次点击，从 1 递增；客户端会重编号 -->
    <Category>Appearance</Category>
    <Trigger>Click</Trigger>
    <TriggerSource></TriggerSource>
    <Duration>3000000</Duration>       <!-- TimeSpan ticks，3e6 = 0.3s -->
    <Delay>0</Delay>
    <AccelerationRatio>0</AccelerationRatio>
    <DecelerationRatio>0</DecelerationRatio>
    <RepeatBehavior>1</RepeatBehavior>
    <Start>1</Start><End>0</End>       <!-- 进入/退出类需要 -->
    <Magnitude>Medium</Magnitude>      <!-- 仅强调类；❌ 不能是 Large -->
    <Frequency>1</Frequency>           <!-- 仅强调类 -->
  </Animation>
</Animations>
```

插入位置：元素块内 `<CanClone>…</CanClone>` **之后**（无 `<CanClone>` 则挂 `<Id>` 之后）。
页面级 `<AnimationOrders>` 挂在**顶层 `</Elements>` 之后**，且**一页只能有一块**（多块要合并）。

### 3.4 客户端会做的规范化（不能当成"注入失败"）

- 重复 `<Number>` 被**顺序重编号**（`1,1,2,2,3,3` → `1..6`）。
- `ScaleIn` 自动补 `<Center>`；`JumpIn` 保留 `<Orientation>`。
- 强调类自动补 `<Magnitude>Medium</Magnitude><Frequency>1</Frequency>`。
- 页面级 `<AnimationOrders>` 收敛成一块。

## 四、动画类型表

程序枚举出的动画池有 **220+ 条**（散落在 `Cvte.Paint.Framework.dll` / `Cvte.Paint.Shell.dll` / `EasiNote.UI.dll`），
但**真正验证过能用的只有下面这些**。

### 4.1 已验证可用（verified）

- **进入 Appearance（11 种）**：`RippleInEffect` 涟漪 · `FadeIn` 淡入 · `JumpIn` 跳入 · `ScaleIn` 缩放 ·
  `RotationIn` 旋转 · `WhirlIn` 回旋 · `TranslateIn` 平移 · `DiagonalWipeIn` 对角线擦除 ·
  `RandomizedLinesInEffect` 随机线条 · `RotationFadeIn` 旋转淡入 · `WhirlFadeIn` 回旋淡入
- **退出 Disappearance（2 种）**：`FadeOut` 淡出 · `RippleOutEffect` 涟漪退出
- **强调 Emphasis（4 种）**：`Flicker` 闪烁 · `Shake` 抖动 · `Heartbeat` 心跳 · `Bounce` 弹跳

### 4.2 未验证（名字来自 DLL 反查 / 第三方样本，可用但无数据佐证）

- 进入：`BlindIn` `DiamondIn` `DissolveInEffect` `DotIn` `DoubleWipeIn` `DownfallInEffect` `FireWorksInEffect`
  `ScrollInEffect` `SpiralScaleIn` `StacksInEffect` `StarIn` `SwirlInEffect` `TranslateFadeIn` `WipeDropIn`
- 退出：`BlindOut` `DiamondOut` `DissolveOutEffect` `DotOut` `DoubleWipeOut` `JumpOut` `RotationOut`
  `RotationScaleOut` `RotationWipeOut` `StarOut` `SwirlOutEffect` `TranslateFadeOut` `TranslateOut` `WaveOutEffect`
  `WhirlFadeOut` `WhirlOut` `DownfallOut`
- 强调：`Wave` `Explosion` `Star` `Fire` `Dot` `Change` `RotationEmphasis`

> 注：`*TransitionEffect` 那一大批是**页面切换**动画，属另一子系统，不是元素动画。

### 4.3 想自己验证一个新类型？探针法

唯一可靠办法：造 scratch enbx（每页 1~2 个元素），逐页试一种候选 → 打开 → 上云 → 回读客户端**自己序列化**的 XML：
- **存活**=原样 ⇒ 可用；**被改写**=字段变了 ⇒ 解析了但不支持该值；**被丢弃**=节点没了 ⇒ 不支持。

## 五、怎么让"多个元素一次点击同时动"

| 方案 | 结果 |
|---|---|
| 给多个元素写相同 `<Number>` | ❌ 被客户端重编号，一次点击只出一个 |
| `Trigger=WithPrevious` | ❌ 整份课件加载失败 |
| **把元素包进 `<Group>`，只给 Group 挂动画** | ✅ **唯一可行** |

```xml
<Group>
  <Elements>
    <Picture>…</Picture>      <!-- ⚠️ 子元素坐标是**相对 Group 左上角**的 -->
    <Text>…</Text>
  </Elements>
  <Id>32位hex</Id>
  <X>..</X><Y>..</Y><Width>..</Width><Height>..</Height>
  <Rotation>0</Rotation><IsLocked>False</IsLocked><CanClone>False</CanClone>
  <HasMask>False</HasMask><RotateOrigin>0.5,0.5</RotateOrigin>
  <SaveInfoMetadata><SupportsFallback>True</SupportsFallback><ImportanceLevel>Important</ImportanceLevel></SaveInfoMetadata>
</Group>
```

动画挂在 `</Elements>` 之后、`<Id>` 之前（与普通元素一致）。客户端能正确解析出 `GroupElement`
—— 与官方 MCP 的 `group_elements` 工具行为一致。
**典型用途**：图 + 图注条 + 图注文字；提问框底 Shape + 提问文字；项目符号 Shape + 要点文字。

> ⚠️ `<Group>` 内嵌一层 `<Elements>`，**不能用"第一个 `<Elements>`/`</Elements>`"定位**，
> 必须按标签**深度配对**（`enbx_anim.elements_span` / `enbx_dump.elements` 已修）。

### 🔴🔴 关键补充：一个元素只能保留一条动画

同一元素写两块 `<Animations>`、或同一块里放两条 `<Animation>`，**上云后客户端只留第一条，其余静默丢弃**（不报错）。
**给 `<Group>` 内的子元素挂动画同样无效**（子元素不是可动画的顶层元素）。

⇒ 想"面板先进入、文字后强调"，必须**拆到两个元素**：Shape 挂 `Appearance`、Text 挂 `Emphasis`（这类页**不分组**）。

### 写动画计划的两个铁律

1. **先 `enbx_dump.py` 拿到真实文字/坐标**，再写计划（子串匹配写错会静默不命中）。
2. **定位用 `index`（分组后逐页 dump 核对），不要用 `match`** —— `enbx_anim._resolve` **Group 优先**，
   `match` 会命中整组、把动画挂到 Group 上（正好踩上面那个雷）。

## 六、从"教学意图"出方案：`anim_presets.py`

```bash
python ../enbx_dump.py "课件.enbx" --json dump.json                  # ① 先转储
python anim_presets.py dump.json --auto --out-group v2/group.json --out-anim v2/anim.json   # ② 出方案
python ../seewo_build.py pipeline.json                               # ③ 跑流水线
```

内置意图 → 效果 → 对应版式：

| 意图 | 效果 | 对应版式 |
|---|---|---|
| `逐条事实` | 项目符号/卡片逐条涟漪进入，收尾文字淡入 | bullets / evidence |
| `多图对比` | 本页分组按阅读顺序依次进入 | cards3 / two_col |
| `流程顺序` | 步骤节点依次跳入 | steps / cards3 |
| `提问→答案` | 内容面板先进 → 收起提问框 → 归纳文字淡入 | evidence / two_col |
| `重点强调` | 对指定文字加「闪烁」（需 `--match`） | 任意 |
| `错误警示` | 对指定文字加「抖动」（需 `--match`） | 任意 |

它只产出**实测可用**的三类 + `Click`，且**同一组元素只挂一条动画**（挂 `<Group>` 上）。产出前会跑校验。

## 七、一句话口诀

- 元素动画 = 进入 / 退出 / 强调，触发只有 Click。
- 要"一起动" → `<Group>`，别写相同 Number，更别写 WithPrevious。
- 强调强度写 Medium 或缺省，**永远别写 Large**。
- 一个元素只留一条动画；"先进入后强调"要拆成两个元素。
- 想验证新类型 → 探针课件 + 上云 + 回读客户端序列化结果。
