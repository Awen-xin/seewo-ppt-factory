# 07 · 踩坑总表（速查）

> 全部为实测。按"症状 → 真相 → 正解"排。分册详版见 `01`–`06`。

## 一、环境 / 连接

| 症状 | 真相 | 正解 |
|---|---|---|
| 7916 返回 502 / 假死 | 代理变量在 | `seewo_config` **导入时已自动剥离** http(s)/all_proxy；若仍异常，手 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy`；405 才是"活着" |
| `find_live_port()` 恒返回 None | 代理把探测送去代理 / 客户端没开 | 先确认代理已清；再确认主进程 **EasiNote** 在跑（只看到 `EasiUpdate*.exe` 不算） |
| MCP 探不到 / 工具调用失败 | 客户端没开或没登录 | 先启动并登录希沃白板；客户端在线时 7916 才可达 |
| 截图目录空、无报错 | 传了相对路径 | 截图路径**必须绝对**（客户端按自己 CWD 解析） |

## 三、动效

| 症状 | 真相 | 正解 |
|---|---|---|
| **整份课件只有 1 页 / 页面全丢** | `Trigger=WithPrevious` | 改用 `<Group>` |
| **同上** | `<Magnitude>Large</Magnitude>` | 只写 `Medium` 或缺省（`<Frequency>` 改大安全） |
| 一次点击只动一个元素 | 多元素写了相同 `<Number>` | 包进 `<Group>`，只给 Group 挂动画 |
| 一组动画上云后只剩 1 条 | **一个元素只能留 1 条动画** | 拆成两个元素（Shape 进入 / Text 强调），这类页**不分组** |
| 给 Group 子元素挂的动画全丢 | 子元素不是可动画顶层元素 | 只给顶层元素或 Group 挂 |
| 动画挂到了整组上 | 用 `match` 定位，Group 优先命中 | 定位用 **`index`**（分组后逐页 dump 核对） |
| 新动画类型"没生效" | 未验证类型 | 探针课件 + 上云 + 回读三态判定 |
| 客户端改了 `<Number>` / 补了 `<Center>` | 这是**规范化**不是失败 | 不用管 |

## 四、上云 / 副本

| 症状 | 真相 | 正解 |
|---|---|---|
| 云端同名课件越积越多 | 每次 sync 都**新建 remoteId** | 发布前 GUI 删同名（见 `04`） |
| 写 `<UpstreamId>` 想覆盖旧记录 | "派生自"语义，**不覆盖** | 无效，别走这条路 |
| GUI 删除静默 0 删除 | 行名带 `[课件]` 前缀没拼 | `FindItemByProperty` 拼 `rowPrefix="[课件]"` |
| 删除确认框等不到 | 守卫词用错 | 用 `30天内可在`（"回收站"是独立超链接节点） |
| 刚上传的记录列表里找不到 | 列表是**缓存快照** | 先点 `RefreshButton` |
| `.ps1` 不报错也不执行 | 无 BOM ⇒ PS5.1 按 GBK 解码，中文注释 → ParserError | `.ps1` **纯 ASCII**；中文放 `$env:TEMP\*.json` 读入 |
| 删除偶发 `FAIL no menu` | 窗口未前置 | 重跑一次通常即成功 |
| 想找"删云课件"MCP 工具 | **61 个里没有** | 只能 GUI 删 |

## 五、验收 / 回读

| 症状 | 真相 | 正解 |
|---|---|---|
| 像"动画全部错位" | 缓存文件名 `Slide_<N>_<stamp>` **字典序**排乱 | 按 `Board_*.xml` 的 `<Item>` 顺序对齐 |
| 单页 Group 子计数差 1 | 云端把 Group 空容器 Shape 计入组内 | **良性**（内容/动画一致），判通过 |
| 云端缓存找不到 `Slides/` | 这层目录是扁平结构 | `Slide_*.xml` 在根下、用 `Board_*.xml` |

## 六、版式 / 内容

| 症状 | 真相 | 正解 |
|---|---|---|
| 相邻页报"轮廓相似" | 校验器算相似度（≥82% 报错） | 相邻页换**真版式**（`variant` 不改轮廓） |
| 内容页报"字数不足" | 按 `teachingIntent` 卡下限 | 补内容或改 `intent`（见 `01`） |
| 文本框被渲染端撑高 | 渲染器"不缩字号、框矮就下撑" | 框高按行高 **1.42** 反算；内容页应为 0 个 |
| 同图渲染两遍 | 模板已消费 `images` 又追加一次 | 模板消费的图**勿再追加** |
| `cards3` 配图报错 | 卡片仅 164px 矮 | 改 `photo_trio` |
| 带图注的图被拒 | 图宽 <200px / 高 <60px | 图宽 ≥200px、高 ≥60px；图注 ≤2 行 |

## 七、字体

| 症状 | 真相 | 正解 |
|---|---|---|
| 圆体没落上 | 该角色 `bold=True` 走 `fonts_bold` | 圆体写进 **`fonts_bold`** |
| 个别字仍是雅黑 | 图注字体**硬编码**（`page_renderer.py:89`） | 已知残留，接受 |
| 字号改大没效果 | `flow()` 装不下自动降到 `min` | `size` 与 `min` **同乘 scale** |
| 想放很大 | 内容不变时上限 scale **1.02** | 先精简 `evidence`/`bullets` 文案 |
| 换字体不生效 | 键名写错 | 键名是 **`"font"`**（不是 `fontFamily`） |

## 八、通用工具

| 症状 | 真相 | 正解 |
|---|---|---|
| Java/Python 起子进程 `EBUSY` | 沙箱可能禁派生 | 改从 Bash 直接执行；别归因成回归 |
| Write 生成的 `.bat` 报怪错 | LF 换行被 cmd 逐行吃字符 | `.bat` **CRLF + GBK + 不出现 `chcp`** |

## 九、口诀

- 顺序：视频最先，分组居中，动画最后，发布收尾。
- 动效：三类 + Click；要"一起动"用 Group；强度永远别 Large。
- 上云：先删同名再传；认 `课件云端 ID：<guid>`；`.ps1` 纯 ASCII。
- 验收：按 `Board_*.xml` 对齐；差异页 = 0。
